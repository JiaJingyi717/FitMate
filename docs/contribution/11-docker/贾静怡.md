## 遇到的问题和解决

1. **问题**：作业文档示例为 FastAPI + Postgres，本项目为 Flask + MySQL。  
   **解决**：保留 `schema_mysql.sql` 初始化卷，健康检查使用 `mysqladmin ping` 与 `python` 访问 `/health`。

2. **问题**：生产环境需非 root 运行。  
   **解决**：镜像中创建 `app` 用户；开发阶段挂载源码时由卷覆盖权限，生产镜像内以 `app` 运行 Gunicorn。

## 心得体会

Docker 让后端与 CI 使用同一套依赖安装方式，减少「我机器上能跑」的问题。多阶段构建把 Gunicorn 运行时与开发依赖分开后，生产镜像更小、也更安全。Compose 里 `depends_on: condition: service_healthy` 能避免 API 在 MySQL 未就绪时反复报错，对 Flask 启动迁移逻辑尤其重要。
