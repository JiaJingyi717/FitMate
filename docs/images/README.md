# 实验报告配图目录

图片按课程讲次分文件夹存放，`docs/report.md` 中统一使用相对路径：

```markdown
![说明](images/<讲次文件夹>/<子目录>/<文件名>)
```

**不要**使用 `C:\Users\...` 绝对路径。

另有 `11、FitMate/` 存放答辩 PPT、录屏等非报告正文插图，不在下表列出。

### 新增截图规范

1. 放入上表对应讲次文件夹；代码截图放 `代码/` 子目录。
2. 文件名与 `report.md` 引用一致（英文 kebab-case 优先，如 `ai-generatePlan.png`）。
3. `report.md` 引用格式：`![说明](images/...)`，路径一律用 `/` 正斜杠。
